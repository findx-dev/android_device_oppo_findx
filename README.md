Device configuration for OPPO Find X
=============================================

The OPPO Find X (codenamed _"PAFM00"_ or _"PAHM00"_) is a high-end smartphone from OPPO.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Qualcomm SDM845 Snapdragon 845
CPU     | Octa-core (4x2.8 GHz Kryo 385 Gold & 4x1.8 GHz Kryo 385 Silver)
GPU     | Adreno 630
Memory  | 8 GB RAM
Shipped Android Version | 8.1 
Storage | 128/256 GB
Battery | Non-removable Li-Po 3730 mAh battery
Display | 1080 x 2340 pixels, 19.5:9 ratio, 6.42 inches, AMOLED
Rear camera 1 | 16MP
Rear camera 2 | 20MP
Front camera | 25MP
